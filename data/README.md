# Данные

Исходные датасеты не хранятся в репозитории. Скачайте их и положите в `data/raw/`:

| Файл | Лабораторная | Ссылка |
|---|---|---|
| `raw/cars.csv` | 1 (регрессия) | по варианту, см. [таблицу вариантов](https://docs.google.com/spreadsheets/d/16Lcwrexcmg3-c1h7MpIKNt3SFQHa9GE5K0j19J-qHN8/edit?usp=sharing) |
| `raw/asteroids.csv` | 1 (классификация) | по варианту, см. [таблицу вариантов](https://docs.google.com/spreadsheets/d/16Lcwrexcmg3-c1h7MpIKNt3SFQHa9GE5K0j19J-qHN8/edit?usp=sharing) |
| `raw/Petitions.csv` | 1 (Word2Vec), 2 (RNN) | [просьбы жильцов](https://drive.google.com/file/d/1oU4WZnxmOwp2isH6Sv9yAk2C_48EJQhh/view?usp=sharing) |
| `raw/tinystories/TinyStories-train.txt` | 3 (GPT) | [TinyStories train](https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStories-train.txt) |
| `raw/tinystories/TinyStories-valid.txt` | 3 (GPT) | [TinyStories valid](https://huggingface.co/datasets/roneneldan/TinyStories/resolve/main/TinyStories-valid.txt) |

Обработанные данные каждая лабораторная сохраняет в своей папке (например, `lab1_torch_w2v/data/`).
